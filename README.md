# 주류소매점에서의 7개월 근무

근무 기간 : 2025-02-10 ~ 2025-08-15 ( 7개월 )

문서 특성 : 유급 아르바이트를 처음으로 장기간 ( 반 년 이상 ) 해보며 겪은 사회 경험을 정리한 문서이다.
<br/><br/>
## [ 요약 ]

돈 버는 일은 정말 쉽지 않으며, 처음에 생각한 장단점과 실제로 시간이 지나며 느껴지는 장단점은 전혀 다르구나 라는 것을 알게 되었다. 또한 초기에 업무에 대한 정보와 요령을 익히는 시기를 지나고 나니 결국에는 고객, 고용주 등의 인간관계에서 오는 상호작용, 마찰, 소통 방식에 더 방점을 두게 된다는 것을 체감하게 된 경험이다.
<br/><br/>
## [ 서론 ]

컴퓨터 공학과에서 학습하는 사람의 보편적 특성이 있다고 한다. 약간 숫기가 없다는 것이다. 그래서 이 경험은 의도치 않게 나에게 매우 큰 도전이 되었다. 왜냐면 꽤나 넓은 매장 안에서 직원이 나 하나 뿐이었으며, 근무 시간인 6시간 ( 12:00 ~ 18:00 ) 동안 가게의 여러 일들을 위임을 받아서 처리해야했기 때문이다. 

그게 왜 숫기와 연관이 있느냐 하면… 그 업무 사항 중에 ‘세일즈’가 있었기 때문이다. 

내가 주도해서 말을 붙이고, 매번 들어오는 고객들의 서로 다른 니즈를 파악하거나 설득하여 판매를 하고, 언어/비언어적인 방식들을 훈련하여 더 물 흐르듯이 고객을 유도하고… 때로는 발표하듯이, 때로는 분위기를 풀듯이 상대의 특성에 따라 다르게 판매를 하는 기술이 필요했던 것이다. 무엇보다 고객층의 경제 수준이 기본적으로 높아서 ( 주류라는 사치품의 특성상 ) 초기에는 그들에게 뭔가를 설득해서 판매한다는 행위 자체에 큰 압박감을 느꼈었다.
